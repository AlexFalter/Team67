The phone opens with P or the PHONE button. It contains Courses, Messages and Alerts. Jane Street invitations offer an actionable limousine request; the rejection stays readable until the player chooses LEAVE THE LIMO to advance the car scene. Challenge completion is confirmed by the server before the invitation is delivered, so accepting it away from the laptop still works. Lime sends a confirmation after the parking photo is accepted. Each incoming message and Moodle alert uses the local GTA notification clip (source in public/audio/gta-phone-notification-credits.md).

Random Moodle events use a room-wide server deadline and question with independent player answers. Players have 30 seconds. Incorrect or missing answers cause a seven-second seated crisis; riders finish their vehicle or scripted encounter before the penalty starts. A correct answer adds ten seconds to the shared round, once per event. The host can toggle random quizzes inside the phone. Restart clears event history and penalties.

Server event values/questions: packages/shared/src/moodle-config.json. Phone UI: apps/client/src/npcPrototype/src/ui/phone/phone.js and src/games/quizzes/phone-quizzes.js. NpcFeature owns phone focus, pointer lock and lifecycle. MoodleEvents validates round/event identity, eligibility, choice range and duplicate submissions.

Phone audio is owned by src/ui/phone/phone-sounds.js. It preloads/decode-caches the GTA V clips, unlocks its Web Audio context on trusted pointer/key input, then plays delayed server notifications through that context. Playback errors and per-cue counts are exposed by state() for debugging. UI cues cover opening, selecting apps/messages/answers, back/home, and closing. Sources are listed in public/audio/gta-phone-notification-credits.md. Audio is stopped and its context/listeners disposed with NpcFeature.
