# Fortnite emote audio

These are Fortnite game audio assets by Epic Games, mirrored by
https://github.com/Franc1sco/Fortnite-Emotes-Extended/tree/master/sound/kodua/fortnite_emotes
They are not synthesized or cover recordings. WAV originals were converted to MP3 (LAME quality 3).

| Game emote | Original asset |
| --- | --- |
| Floss | athena_emote_floss_music.wav |
| Orange Justice | hip_hop_good_vibes_mix_01_loop.wav |
| Take the L | athena_music_emotes_takethel.wav |
| Dance Moves | ninja_dance_01.mp3 |
| The Robot | athena_emote_robot_music.wav |
| Dab | No audio: the original single Dab is silent (not Infinite Dab). |

The source plugin's `CreateEmote` mappings associate these clips with the corresponding
Fortnite animations; `Emote_Dab` explicitly uses an empty sound name.
These third-party game assets retain their original ownership; the repository's code
license does not grant redistribution rights for these assets.
