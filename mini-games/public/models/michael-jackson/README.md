# Michael Jackson dancer

Original stylized model authored for this game in Blender, with a fedora, sequinned jacket, white socks and one white glove. No external character mesh or texture was used.

Editable scene: `assets/blender/michael-jackson.blend`.
Rebuild: `/Applications/Blender.app/Contents/MacOS/Blender --background --python assets/blender/build-michael-jackson.py`.

The GLB contains a two-second looping moonwalk animation. Its root stays in place; the host moves the character backward around a validated ground-level loop. Runtime location and movement are supplied through the feature placement rather than baked into the asset.
